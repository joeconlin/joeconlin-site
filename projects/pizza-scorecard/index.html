Pizza Scorecard

A small web app for scoring pizza spots on crust, sauce, cheese, and overall flavor, with a group leaderboard.

Status · Live

Try it ↗Source on GitHub ↗

View as Markdown ↗

Pizza Scorecard lets a group score pizza spots on four things (crust, sauce, cheese, and overall flavor) and rolls everyone’s scores into a leaderboard with category winners.

It’s a React front end on Vercel with a small Express API on Render (source). The first load can take a few seconds while the API wakes up.
