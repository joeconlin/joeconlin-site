![The Pizza Scorecard leaderboard, with category winners and top-ranked New Haven pizza spots led by Frank Pepe Pizzeria Napoletana.](https://joeconlin.org/images/pizza-scorecard.jpg)

The live leaderboard.

Pizza Scorecard lets a group score pizza spots on four things (crust, sauce, cheese, and overall flavor) and rolls everyone’s scores into a leaderboard with category winners.

It’s a React front end on Vercel with a small Express API on Render ([source](https://github.com/joeconlin/pizza-ranking-backend)). The first load can take a few seconds while the API wakes up.
